# Simple Interest Calculator

This project is a simple interest calculator implemented using a Bash shell script.

## Description

The calculator asks the user to enter:
- Principal amount
- Rate of interest
- Time period

It then calculates simple interest using the formula:

**Simple Interest = (Principal × Rate × Time) / 100**

## Usage

Run the script in a Bash terminal:

```bash
bash simple-interest.sh
```

## Example

Enter principal: 1000

Enter rate of interest: 5

Enter time period in years: 2

Simple Interest: 100

- Bash scripting
